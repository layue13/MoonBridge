# 设计文档

文档描述当前实现；源码与自动化测试是行为核对依据。项目仍在开发，尚未完成目标整合包和生产环境验收。

| 文档 | 内容 |
| --- | --- |

| [插件开发](plugins.md) | 生命周期、玩家/服务器视图、选服、命令、连接与登录检查 |
| [运行配置](operations.md) | 认证、接入限制、超时、启动和部署边界 |

| [验证方法](testing.md) | 自动化测试、烟测、真实客户端与合成性能测量 |

设计约束：核心管理连接和协议；插件负责玩法与访问策略。`ServerView` 是后端目录快照，发现方式是目录的提供者，不引入核心负载观测。插件回调离开 I/O 线程执行；常规 PLAY 转发不调用连接访问检查。
